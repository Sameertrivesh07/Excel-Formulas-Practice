# Excel Formulas Practice Project

## 📊 Project Overview

This project demonstrates the practical use of **12 commonly used Excel formulas/functions** with sample datasets and real-world style examples.

The project focuses on developing practical Excel skills for **data analysis, lookup operations, conditional calculations, filtering, counting, text manipulation, and data handling**.

## 🛠️ Tools & Skills Used

* Microsoft Excel
* Excel Formulas & Functions
* Data Analysis
* Data Lookup & Retrieval
* Data Filtering
* Conditional Calculations
* Data Cleaning

## 📌 Excel Functions Covered

1. **VLOOKUP** – Searches for a value in a table and returns the corresponding information.
2. **HLOOKUP** – Searches for a value horizontally across rows and returns the corresponding information.
3. **XLOOKUP** – Performs flexible lookups and returns matching data from a specified range.
4. **Picture Lookup** – Demonstrates lookup functionality using images.
5. **FILTER** – Filters data based on specified conditions.
6. **IFERROR** – Handles formula errors and returns an alternative result.
7. **& (Concatenation)** – Combines text from multiple cells.
8. **TEXTJOIN** – Combines text from multiple cells using a specified delimiter.
9. **SUMIF** – Calculates the sum of values based on a single condition.
10. **SUMIFS** – Calculates the sum of values based on multiple conditions.
11. **COUNTIF** – Counts cells that meet a specific condition.
12. **COUNTIFS** – Counts cells that meet multiple conditions.
