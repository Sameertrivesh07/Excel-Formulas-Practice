# Excel Formulas Practice Project

## 📊 Project Overview

This project demonstrates the practical use of 12 commonly used Excel formulas/functions with sample datasets and real-world style examples.

The project is designed to improve Excel data analysis, lookup, conditional calculation, counting, filtering, and text-handling skills.

## 🛠️ Tools Used

* Microsoft Excel
* Excel Formulas
* Data Analysis
* Data Lookup & Filtering

## 📌 Excel Functions Covered

1. **VLOOKUP** – Used to search for a value in a table and return related information.
2. **HLOOKUP** – Used to search for data horizontally across rows.
3. **XLOOKUP** – A modern lookup function used to find and return matching data.
4. **Picture Lookup** – Demonstrates lookup functionality with images.
5. **FILTER** – Used to filter data based on specific conditions.
6. **IFERROR** – Used to handle and replace formula errors.
7. **& (Concatenation)** – Used to combine text from multiple cells.
8. **TEXTJOIN** – Used to combine text from multiple cells with a delimiter.
9. **SUMIF** – Used to calculate totals based on a single condition.
10. **SUMIFS** – Used to calculate totals based on multiple conditions.
11. **COUNTIF** – Used to count cells that meet a specific condition.
12. **COUNTIFS** – Used to count cells based on multiple conditions.
